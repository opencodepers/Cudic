Credits

Cudic is assembled from a lot of other people's work. This page names the software, art, type and services it uses, and the licence each one is used under — so a licence question has an answer rather than a guess.

Last updated 23 November 2026.

Visual Studio Code and Monaco

Studio is not a lookalike editor: it runs Visual Studio Code's open-source workbench and Monaco in the browser. The workbench, the editor, the Explorer, the command palette, keybindings and language services come from VS Code and Monaco, © Microsoft Corporation, released under the MIT licence. The bindings that let them run outside Electron are @codingame/monaco-vscode-api 37.1.0 and its service packages, by Codingame, also MIT. The classic editor page loads monaco-editor 0.45.0 from jsDelivr.

Cudic's branding, activity bar, Preview panel, project switcher and AI panel are Cudic's own and are not part of VS Code. Cudic is not affiliated with or endorsed by Microsoft.

  • Visual Studio Code — MIT, © Microsoft Corporation.
  • Monaco Editor — MIT, © Microsoft Corporation.
  • Codingame's monaco-vscode-api — MIT, the browser workbench bindings.

Libraries

Every file below is used as published; Cudic does not relicense any of them.

  • Runtime, data and realtime — @supabase/supabase-js 2.x (MIT) for authentication, database and storage; ws (MIT) for the WebSocket server.
  • Viewers — three.js 0.163 (MIT) for 3D models; xterm.js 5.3 (MIT) for the terminal view; SheetJS 0.18.5 (Apache-2.0) for spreadsheets; @aiden0z/pptx-renderer 1.3.0 (Apache-2.0) for slide decks.
  • Studio — Yjs and y-webrtc (MIT) for peer-to-peer collab; isomorphic-git and @isomorphic-git/lightning-fs (MIT) for source control; JSZip (MIT or GPL-3.0-or-later) for archives; Mammoth (BSD-2-Clause) for .docx import; Vite (MIT) for the build.
  • Motion — GSAP 3.15 under GreenSock's standard "no charge" licence.
  • Icons — Lucide (ISC) for Studio chrome and inline interface icons. The rail's 8×8 icons are Cudic's own, not Lucide's.
  • Scratch — TurboWarp's Scaffolding loader plays imported Scratch projects. Scratch itself is a project of the Scratch Foundation; Cudic is not affiliated with it.
  • Email and push — Nodemailer (MIT-0), Resend (MIT) and web-push (MPL-2.0) for verification mail and notifications.

Art, icons and type

  • Kenney — the 674 game, board-game and emote icons bundled under /assets/kenney, plus the 3D models the asset picker streams, are CC0 1.0 by Kenney. CC0 asks for no credit; it is given anyway, because good art deserves it.
  • Cudic asset pack — the wordmark, 83 icons on an 8×8 grid, 30 emoji and the cursor sets are drawn for and shipped with Cudic.
  • Geist and Geist Mono — by Vercel, under the SIL Open Font License 1.1, served from Google Fonts. They carry every page.
  • Satoshi — by the Indian Type Foundry, under the Fontshare free-font licence, used on the landing and 404 pages.
  • Nine Circles — used for the Cudic wordmark under its free commercial licence.

Hosting and services

These run the site. Each has its own terms and privacy policy, which govern the data it handles.

  • Vercel — serves the website, its rewrites and cache headers.
  • Render — runs the API, chat sockets, share cards and game hosting.
  • Supabase — Postgres database, authentication and file storage.
  • Google Fonts — delivers Geist and Geist Mono.
  • jsDelivr — serves the pinned library files the editor and viewers load.
  • Cloudflare Turnstile — the bot check on signup, password reset and account deletion.
