Start here

Five steps from an empty tab to a game someone can play.

You do not need to read the docs first. Do these in order, one sitting, and you will have a link you can send to someone. Every step links the single page that covers it.

Roughly an afternoon. Nothing to install — everything runs in the browser.

  1. Pick a starting point

    A template already runs. Start from one instead of an empty folder, then change what it says — text first, physics second. The platformer and clicker templates are the two that teach the most per edit.

    Open Studio Ctrl+Shift+P → “Cudic: Start from template” Platformer cookbook

  2. Make it run

    Save the file, watch the preview. When something throws, the console under the preview names the file and line — that is the fastest loop you have, so learn to keep it open.

    Draw with canvas Studio reference

  3. Let it remember

    A game with progress is a game people come back to. One script gives you saving, best scores and a “continue” that follows the account instead of the browser.

    Cloud saves How saving works

  4. Grab art in about ten seconds

    Press Ctrl+Shift+P and run Cudic: Insert asset. The whole Kenney library is searchable — CC0, so no credit is legally required, though the credit line is already generated for you. Sprites, emotes and 3D models all land in assets/kenney/.

    Files and assets CC0 1.0 · Kenney

  5. Ship it

    Save keeps the project. Ship saves, publishes, and hands you the URL — that is the whole release. Each ship becomes a numbered version, so you can go back to the one that worked.
