Take a theme with you.

Every free pack in the theme store is a .ctheme file: a short, readable list of colours, fonts, icons, motion and a background scene. Save one here, keep it, or paste it into the builder to make it yours.

No account, no install step, no binary blob — just text you can read in any editor.

02

It opens in a text editor

One directive per line, # for comments, last value wins. The compiler and the server share the same allowlists, so a file that compiles will also save.

starter.cthemeplain text

        

        

          

            01
            
Name first

            
name is the only required line — 2 to 40 characters. Everything else is optional.

          

          

            02
            
Hex colours only

            
Eight keys: ink panel raised line signal tp ts tt, each #rrggbb.

          

          

            03
            
Scenes or images

            
background scene city-night or an https:// image. Scenes take up to eight numeric params.

          

          

            04
            
No code inside

            
No scripts, no imports, no local files. The builder's Advanced tab holds CSS and HTML separately.
