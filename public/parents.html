What it is

the short version

A browser studio for small games: an editor with a file tree and live preview, a one-click publish pipeline, a gallery community, and built-in multiplayer and saves. The whole loop — write, run, publish, share, talk — happens in one tab.

Real code, not blocks

Students write HTML, CSS and JavaScript, or Python through a browser runtime. Scratch blocks they already know can be imported and preserved — the .sb3 moves to, not translates into, editable files they can grow past.

Publishing is motivation

One click turns a project into a page with a link, comments and embed snippets. Finish a game, share it with the class, watch someone other than a teacher play it. That deadline does more for completion rates than any rubric.

Runs on what you have

No installs, no admin rights, no build tools — it runs in the browser, so Chromebooks and lab machines work. A slow preview is a WiFi complaint, not a broken install.

Free, with no paid tier

Cudic is free. There are no paid tiers, no premium unlocks and no limits on publishing. Ads on the site keep it free; nothing asks a student for money.

For teachers

pick it up in one lesson
STEP 1First lesson in ten minutes

Open Studio, paste the Clicker guide into a file, preview live in the same tab. The Cookbook guides are complete, working pages students can change line by line and see the result instantly.

STEP 2Grow from Scratch

Already teach Scratch? Import an .sb3 or paste a project link. Cudic converts it into a real editable project — sprites, sounds and scripts intact — so the class moves from blocks to text on familiar ground instead of restarting from zero.

STEP 3Ship a class jam

Every published game gets a share link, comments and leaderboards built in. Set a deadline, publish the room link via the embed snippet, and let students judge each other's work on the game page instead of on a screen respectably turned to face the wall.

Differentiated by default

Fast finishers take the multiplayer guide and ship two-player versions; students new to code keep editing colors, speeds and text in the same project. Everyone is inside the same file set, just at different depths.

Structures they already know

Projects are plain files you can copy, version and re-ship. The docs cover saves, multiplayer and publishing; every game page doubles as a working example students can open, fork and extend.

For parents

what to expect

Cudic is kid-adjacent by design, not by marketing: the accounts are usernames, publishing is one click, and every game page has a report button moderated by a real team. Accounts are free and only need the basics to create.

MODERATION & REPORTS, BUILT IN
Who they talk to

Chat and comments exist and are moderated — reports go to a moderation team, not a wall of silence. Games without a published page can't be found; private drafts stay private.

No spending traps

Coins are a fun reward within the site, not a currency you will ever be asked to buy. The FAQ's answer to "what does it cost?" is one word, and no feature sits behind a credit card.

What's on an account

A username, saved games, and progress in games with cloud saves. No phone number is required, and what they make lives in their own Studio drafts until they choose to publish it.

Quick answers

the full list lives in the FAQ
+What does it cost?

Nothing. Cudic is free to use — ads on the site keep it free, and there are no paid tiers or publishing limits.

+Do we need to install anything?

No. The studio, the live preview and the player all run in the browser. If the lab can open a web page, it can run Cudic.

+Can we import our existing Scratch projects?

Yes. Upload an .sb3 or paste a Scratch link; Cudic converts it into an editable HTML5 project with sprites, sounds and scripts intact.

+Is my child talking to strangers?

The site has chat and comments, both moderatable through report buttons that go to a real moderation team. Games and drafts are unpublished by default, and accounts are usernames — no personal info is required to sign up.

+What languages can students build with?

HTML, CSS and JavaScript — including multi-file ES modules and npm packages that run in the browser — plus Python through a browser runtime. There is no server-side execution.

+Can students play each other's games?

Yes. Published games are playable in the gallery with one tab, embeddable anywhere with copy-paste snippets, and support cross-device saves plus multiplayer rooms of up to 32 players.
