Accessibility

What works today, what is being fixed, and how to report something you cannot use. Plain version: Cudic aims at WCAG 2.1 AA but has not been audited, and we fix reported barriers rather than claiming conformance.

Last updated 14 November 2026.

This statement

Cudic is built and run by one developer, not an agency with an accessibility budget. This page says what is true today rather than what we wish were true: we aim at WCAG 2.1 level AA, we have not paid for an audit, and we do not claim conformance yet.

What is in place

  • Every page has a meaningful title, a language attribute, and keyboard-reachable navigation.
  • Decorative icons carry aria-hidden; interactive controls carry a label.
  • Text contrast is checked against both the dark and light themes as a shipping rule.
  • Motion can be switched off in profile settings, and the game player respects prefers-reduced-motion.
  • Errors in forms and chat appear as text, not colour alone.
  • Games run in a sandboxed frame, so a broken or flashing game is contained rather than taking the page with it.

Known gaps

  • The Studio editor is dense: screen-reader traversal of the file tree and the code editor is workable but slow.
  • Some tertiary text in the dark theme sits close to the 4.5:1 line and is being raised.
  • Drag-and-drop ordering has no complete keyboard equivalent outside chat and collections.
  • Games published by other users are outside our control: an unusable one can be removed, but not every user-made game can be promised to be accessible.

Report a barrier

If something here stops you using Cudic, email nathen.t2023@gmail.com with the page, what you tried to do, and the assistive technology you were using. We aim to reply within 10 working days, and blocking issues are fixed before cosmetic ones. A suggested fix is genuinely useful and usually ships faster than a report without one.

If we get it wrong

This statement is not a legal conformance claim and is not a substitute for rights you have under the Equality Act 2010. It is a plain record of where the site stands and how to get a barrier fixed.
