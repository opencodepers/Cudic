# Cudic — a browser studio for making games

**Open a tab. Build a game. Publish it to a real gallery with players in it.**

No installs. No accounts at other services. No "deploy this yourself."
Cudic is entirely in the browser — a workbench on the left, your game on the
right, and the gallery one click away.

👉 **[Open Cudic now — free](https://cudic.vercel.app/)**

---

## What's actually in it

- **Studio** — a VS Code-style workbench: file explorer, editor tabs, live
  preview, command palette. Write HTML/CSS/JS by hand, import files or whole
  folders, or paste code straight in.
- **Publish** — every game gets a permanent page with card art, comments,
  likes, star ratings, and one-click **fork/remix** (credit travels up the
  remix chain automatically, like Scratch or GitHub forks).
- **Cloud saves** — sign in and your progress follows your account across
  every device. Games opt in with one script tag.
- **Multiplayer** — published games can open live rooms, up to 32 players.
  Guests can join without an account, and names are set by the server so
  nobody can pretend to be you.
- **Snapshots** — Studio records exactly *what changed* since your last
  snapshot (you pick which files to stage) and restores any version back.
  It's version control aimed at people who've never used git.
- **Scratch import** — a `.sb3` file or a shared link becomes an editable
  Cudic project, runnable as-is.
- **The rest** — theme packs that restyle the whole site, servers & DMs,
  quests, a coins economy that can never be bought with money, and a built-in
  AI panel that can read your project files and apply fixes.

## Who it's for

Kids (and grown-ups) who want to go from *nothing* to *published* in one
afternoon, in the same tab, without the setup that usually eats that
afternoon.
